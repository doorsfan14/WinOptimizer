Safety is the product

Measure first. Change only what you understand.

WinOptimizer is built as a trustworthy system utility. It runs without administrator permissions for ordinary monitoring and never changes settings in the background.

01

Read the current state

Windows APIs and supported sensors provide the values. Missing or incomplete readings stay marked unavailable.

02

Review the proposed change

See the affected startup value or exact cleanup scope; power-plan changes are limited to AC power, and drive maintenance delegates to Windows.

03

Confirm and verify

Startup changes are backed up locally and checked after writing. File deletions are permanent and clearly labeled.

04

Keep the record here

The latest activity is stored locally. No account, network connection, or diagnostic upload is required.

Protections that stay on

Defender, Firewall, UAC, and Windows UpdateNever disabled as an optimization shortcut.
Essential Windows processes and servicesNever terminated or disabled automatically.
Fan speed and temperature controlsRead-only monitoring; no hardware control commands.
Compatibility and install

Built for Windows desktops.

The project is in development. This repository has source code and an installer recipe; there is no verified release binary yet.

Supported platform targets

  • Windows 11 x64 and ARM64 are the primary targets.
  • Windows 10 Enterprise/LTSC editions supported by .NET 10 are targeted; hardware telemetry varies by device and firmware.
  • Windows 7/8 and 32-bit Windows are not supported.
  • Read-only monitoring runs as the signed-in user; drive maintenance alone may request UAC approval.

Build from source

  • Windows 10 or 11 development machine.
  • .NET 10 SDK and Windows Desktop workload/runtime.
  • Visual Studio 2022 17.14+ or the .NET CLI.
  • NuGet restore for WPF and LibreHardwareMonitor dependencies.

Frequently asked questions

Clear answers, even when the sensor is missing.

Why does fan speed say unavailable?

Windows does not expose fan RPM on every PC. WinOptimizer checks the sensors LibreHardwareMonitor can access. Firmware and motherboard support vary; unavailable does not mean the fan is broken.

Does a high memory percentage mean I need more RAM?

Not by itself. Windows uses spare memory for caching. WinOptimizer shows available physical RAM separately from committed virtual memory and only calls out low availability alongside high use.

Will it make my PC faster automatically?

No. It measures and explains first. Recommendations are contextual; each supported action requires your confirmation. There are no arbitrary speed multipliers or background tweaks.

Is my diagnostic data sent anywhere?

No telemetry or diagnostic upload is implemented. Settings, event history, startup backups, and error logs remain in your local Windows profile.

Can I restore a startup change?

Yes. Current-user Run-key values are backed up before disable, verified after the change, and can be restored from Startup or History. System-wide entries are read only.

Can cleanup restore deleted files?

No. Cleanup is limited to selected old .tmp, .temp, and .cache files directly inside the current user's temporary folder. Preview each file list and confirm before permanent removal.

Does storage capacity report drive health?

No. Free space is not a health test. The application reports a health assessment only when a supported source can provide one; that assessment is not available in this release.

Why is there no download button?

The first verified installer has not been published. Follow the repository's Releases page for actual assets. The source is available now.
